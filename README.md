# DroniC — Drone Photography & Web Development Platform

## Project Overview

DroniC is a personal drone photography and full-stack web development project created by Daksh Patel.

The platform combines aerial photography, cinematic storytelling, and modern web development.

Initially developed as a static website using HTML, CSS, JavaScript, and Bootstrap, DroniC is being transformed into a dynamic application using Django's Model-View-Template (MVT) architecture.

## Project Objectives

- Showcase drone photography and cinematic videos.
- Develop a dynamic gallery managed through Django.
- Implement database-driven content management.
- Build a functional contact system.
- Explore authentication, security, APIs, and cloud deployment.
- Apply software-engineering principles throughout development.
