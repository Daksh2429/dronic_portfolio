# DroniC — Project Vision

## Vision

To develop DroniC into a professional drone photography and cinematography platform while using it as a practical environment for learning full-stack web development.

## Problem Statement

The existing static website requires manual modification of HTML files whenever new photography, videos, or project information is added.

It also lacks persistent data storage, a functional backend for visitor inquiries, and an administrative interface for managing content.

## Proposed Solution

Transform DroniC into a dynamic Django web application that separates presentation, application logic, and data management.

## Initial Scope

1. Retain and improve the existing frontend.
2. Implement Django using MVT architecture.
3. Introduce database-backed photo and video management.
4. Provide a secure administration interface.
5. Implement visitor contact functionality.
6. Deploy the application to a cloud-hosting environment.

## Future Possibilities

- Interactive drone photography galleries.
- Location-based photography collections.
- Advanced search and filtering.
- REST APIs.
- User accounts and permissions.
- Cloud-based media storage.
- Automated testing and CI/CD.

## Development Principles

- Develop incrementally.
- Understand technical decisions before implementation.
- Separate application responsibilities.
- Maintain Git version history.
- Document significant architectural decisions.
- Protect credentials and sensitive information.
- Prioritize maintainable, reusable code.
